# Báo cáo bài tập cá nhân – ASP.NET Core MVC

Thư mục này lưu **báo cáo kết quả thực hiện** và **ảnh chụp màn hình minh chứng** cho bài tập cá nhân môn Phát triển ứng dụng Thương mại điện tử.

## Cấu trúc thư mục

```text
Report/
├── README.md
├── BaiTap_CaNhan_ASP_CORE_LMS.docx
└── images/
    ├── Hình 1.1.png
    ├── Hình 2.1.png
    ├── Hình 2.2.png
    ├── ...
    └── Hình 10.9.png
```

## 1. Báo cáo Word

File báo cáo cần được đặt tên đúng theo yêu cầu đề bài:

`BaiTap_CaNhan_ASP_CORE_LMS.docx`

Báo cáo trình bày quá trình xây dựng website TanQuy Cinema bằng ASP.NET Core MVC, bao gồm:

- Môi trường phát triển và các công cụ sử dụng.
- Khởi tạo ứng dụng ASP.NET Core MVC và cấu hình SQL Server.
- Thiết kế Model, DbContext, Migrations và quản lý dữ liệu.
- Quản lý phim, thể loại và upload hình ảnh.
- Xây dựng giỏ hàng bằng Session.
- Checkout, lưu đơn hàng và gửi email thông báo.
- Tùy chỉnh giao diện và triển khai website trên Somee.
- Khó khăn, kết quả thực hiện, hạn chế và hướng cải thiện.

Báo cáo có mục lục chính, mục lục hình ảnh và mục lục bảng biểu. Khi cập nhật hoặc thay đổi số trang, cần kiểm tra lại các mục lục trong Microsoft Word trước khi nộp.

## 2. Ảnh minh chứng

Đặt ảnh được sử dụng trong báo cáo tại thư mục `images/`.

Quy ước đặt tên ảnh theo số hình trong báo cáo, ví dụ:

- `Hình 1.1.png`
- `Hình 2.1.png`
- `Hình 5.10.png`
- `Hình 10.9.png`

Tên file nên khớp với chú thích hình tương ứng trong báo cáo để thuận tiện đối chiếu. Có thể sử dụng định dạng PNG hoặc JPG; ưu tiên giữ độ rõ nét và nội dung cần chứng minh.

Ảnh minh chứng cần là ảnh thực tế trong quá trình thực hiện. Trước khi đưa lên repository, cần che thông tin nhạy cảm như mật khẩu, connection string, App Password, thông tin đăng nhập và dữ liệu cá nhân không cần thiết.

## 4. Lưu ý khi nộp bài

1. Đảm bảo file Word có tên `BaiTap_CaNhan_ASP_CORE_LMS.docx`.
2. Đảm bảo các ảnh trong `images/` tương ứng với chú thích trong báo cáo.
3. Kiểm tra lại mục lục, mục lục hình ảnh, mục lục bảng biểu và số trang sau lần cập nhật cuối.
4. Không đưa mật khẩu, connection string có thông tin xác thực, App Password hoặc dữ liệu nhạy cảm lên GitHub.
5. Nộp file Word và các đường dẫn GitHub/website trên LMS theo hướng dẫn của lớp học phần.
